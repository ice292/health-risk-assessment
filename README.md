# งานที่ 1: ระบบลงทะเบียนและประเมินความเสี่ยงสุขภาพเบื้องต้น
### Patient Health Risk Assessment and Registration System

เว็บแอปพลิเคชันเพื่อคัดกรองผู้ป่วยเบื้องต้นก่อนเข้ารับการรักษา สำหรับองค์กรบริการสุขภาพ ช่วยรับข้อมูลส่วนบุคคล คำนวณค่าดัชนีมวลกาย (BMI) ประเมินความเสี่ยงตามเงื่อนไขทางการแพทย์ และออกใบสรุปผลการคัดกรองเพื่อลดเวลาการทำงานของเจ้าหน้าที่หน้าร้าน

---

## 🌟 ฟังก์ชันการทำงานหลัก (Core Features)

### 1. การตรวจสอบความถูกต้องของข้อมูล (Input Validation)
- ตรวจสอบความถูกต้องของข้อมูลป้อนเข้าแบบ Realtime และก่อนกดประเมิน:
  - **ชื่อ-นามสกุล**: ตรวจสอบว่าไม่เป็นค่าว่าง และมีความยาวเหมาะสม
  - **อายุ**: ตรวจสอบว่าเป็นตัวเลขจำนวนเต็มบวก (1 - 120 ปี)
  - **น้ำหนัก (กก.)**: ตรวจสอบว่าเป็นตัวเลขที่ถูกต้อง (10 - 300 กก.)
  - **ส่วนสูง (ซม.)**: ตรวจสอบว่าเป็นตัวเลขที่ถูกต้อง (50 - 250 ซม.)
- หากพบข้อมูลไม่ถูกต้องหรือช่องว่าง ระบบจะแสดงข้อความเตือนผ่านคอมโพเนนต์ **`Alert`** และแสดง `error` พร้อมข้อความแนะนำใต้ช่องป้อนข้อมูล โดยปฏิเสธการประเมินผลจนกว่าจะแก้ไขข้อมูลให้ถูกต้อง

### 2. การประเมินและจัดกลุ่มความเสี่ยง (Risk Assessment Logic)
- **การคำนวณค่า BMI**:
  $$\text{BMI} = \frac{\text{น้ำหนัก (kg)}}{(\text{ส่วนสูง (cm)} \div 100)^2}$$
- **เกณฑ์การจัดกลุ่มความเสี่ยง (3 ระดับ)**:
  1. 🟢 **ความเสี่ยงต่ำ (Low Risk)**:
     - ค่า BMI อยู่ในเกณฑ์มาตรฐานสมส่วน (18.5 - 22.9 กก./ม.²)
     - ไม่สูบบุหรี่
     - ไม่มีโรคประจำตัวเรื้อรัง
  2. 🟠 **ความเสี่ยงปานกลาง (Moderate Risk)**:
     - ค่า BMI อยู่ในเกณฑ์น้ำหนักเกิน/ท้วม (23.0 - 24.9) หรือน้ำหนักน้อยกว่าเกณฑ์ (< 18.5)
     - หรือ สูบบุหรี่เป็นครั้งคราว
     - หรือ มีประวัติโรคประจำตัวเรื้อรังระดับปานกลาง (เช่น ความดันโลหิตสูง, โรคเบาหวาน, ไขมันในเลือดสูง)
  3. 🔴 **ความเสี่ยงสูง (High Risk)**:
     - ค่า BMI อยู่ในเกณฑ์โรคอ้วนรุนแรง (BMI ≥ 30) หรือเป็นโรคอ้วนร่วมกับสูบบุหรี่ประจำ
     - หรือ มีโรคประจำตัวกลุ่มเสี่ยงสูง (เช่น โรคหัวใจและหลอดเลือด, โรคไตเรื้อรัง, มีหลายโรคเรื้อรังร่วมกัน)
     - หรือ สูบบุหรี่ประจำร่วมกับโรคประจำตัวเรื้อรัง

### 3. การแสดงผลลัพธ์ (Result Display & Summary)
- แสดงหน้าต่างสรุปผลข้อมูลผู้ป่วยผ่าน **`Dialog`**
- สรุปข้อมูลผู้ป่วย, สัดส่วนร่างกาย, ค่า BMI และการแปลผล
- แสดงระดับความเสี่ยงสุขภาพด้วย **`Chip`** สีสัญลักษณ์ (เขียว / ส้ม / แดง)
- สรุปรายการปัจจัยเสี่ยงที่ตรวจพบ
- แสดง **ข้อแนะนำการปฏิบัติตน (Actionable Recommendations)** เฉพาะบุคคลตามระดับความเสี่ยง
- รองรับการพิมพ์ใบสรุปผลการคัดกรองหรือบันทึกเป็น PDF (`window.print()`) พร้อมฟอร์มลงนามทางการแพทย์

## 🎨 รายการ Material-UI (MUI) Components ที่ใช้งาน
ตามข้อกำหนดของงาน:
- **Structure & Layout**:
  - `Container`: กำหนดขอบเขตความกว้างของหน้าจอ
  - `Paper`: กล่องการ์ดพื้นหลังพร้อมเงา Elevation
  - `Grid`: จัดวางโครงสร้างฟอร์มแบบ Responsive (แบ่งคอลัมน์บนมือถือและจอคอมพิวเตอร์)
  - `Stack`: จัดระยะห่างระหว่างองค์ประกอบแนวตั้งและแนวนอน
- **Inputs**:
  - `TextField`: รับค่าชื่อ-นามสกุล, อายุ, น้ำหนัก, ส่วนสูง
  - `RadioGroup` / `Radio`: เลือกเพศ และ เลือกพฤติกรรมการสูบบุหรี่
  - `Select` / `MenuItem`: เมนูเลือกกลุ่มโรคประจำตัว
  - `Button`: ปุ่ม "ประเมินผลความเสี่ยง" และ ปุ่ม "ล้างข้อมูล"
- **Feedback & Displays**:
  - `Alert`: กล่องแจ้งเตือนความผิดพลาดเมื่อกรอกข้อมูลไม่ถูกต้อง
  - `Dialog`, `DialogTitle`, `DialogContent`, `DialogActions`: หน้าต่าง Modal สรุปผลการประเมิน
  - `Chip`: แสดงป้ายกำกับสถานะระดับความเสี่ยงพร้อมสีตามเกณฑ์

## 🚀 วิธีการนำขึ้น GitHub Pages (Step-by-step Guide)

### ขั้นตอนที่ 1: สร้าง Repository บน GitHub
1. เข้าไปที่ [https://github.com/new](https://github.com/new)
2. ตั้งชื่อ Repository เช่น: `health-risk-assessment`
3. เลือกเป็น **Public**
4. กด **Create repository**

### ขั้นตอนที่ 2: Push โค้ดขึ้น GitHub
เปิด Terminal / PowerShell แล้วรันคำสั่งต่อไปนี้ (แทนที่ `<YOUR_USERNAME>` ด้วยชื่อ GitHub ของคุณ):

```bash
cd c:\Users\ไอซ์\Downloads\ทดลอง\health-risk-assessment

git init
git add .
git commit -m "feat: complete patient health risk assessment system"
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/health-risk-assessment.git
git push -u origin main
```

*(ตัวอย่าง: หากใช้ Username `ice292` URL จะเป็น `https://github.com/ice292/health-risk-assessment.git`)*

### ขั้นตอนที่ 3: เปิดใช้งาน GitHub Pages
1. ไปที่หน้า Repository ของคุณบน GitHub
2. คลิกแท็บ **Settings** ด้านบน
3. เมนูด้านซ้ายเลือก **Pages**
4. ในหัวข้อ **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **main** และโฟลเดอร์เป็น **/ (root)**
5. กดปุ่ม **Save**

### ขั้นตอนที่ 4: เข้าชมเว็บไซต์
รอประมาณ 1 - 2 นาที เว็บไซต์จะออนไลน์ทันทีที่ URL:
```
https://<YOUR_USERNAME>.github.io/health-risk-assessment/
```
*(ตัวอย่าง: `https://ice292.github.io/health-risk-assessment/`)*
